# Sistema de Alquiler de Vehículos

Proyecto realizado en Python aplicando conceptos de Programación Orientada a Objetos.

## Funcionalidades

El programa permite:

* Trabajar con vehículos de tipo Auto, Moto y Camioneta.
* Tener vehículos precargados en una lista.
* Listar los vehículos disponibles.
* Crear clientes.
* Crear reservas seleccionando un vehículo disponible.
* Calcular el costo del alquiler según el tipo de vehículo.
* Cambiar el estado de una reserva.
* Registrar los cambios de estado en el historial.
* Manejar errores mediante excepciones.

## Estado del proyecto

El proyecto se encuentra minimamente funcional y en desarrollo.
